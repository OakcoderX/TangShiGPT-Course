# 来源与 GitHub 发布说明

## 上游来源

- 课程起点为 Andrej Karpathy 的字符级 GPT 教程。早期项目曾直接改造其示例。课程包提供独立编写的 PyTorch 教学入口，Karpathy 的原始示例通过上游链接阅读。未在该 Gist 核实到明确再分发许可，因此没有把 Gist 原码或旧版直接改写脚本放入公开包。[microgpt 讲解](https://karpathy.github.io/2026/02/12/microgpt/) · [原始 Gist](https://gist.github.com/karpathy/8627fe009c40f57531cb18360106ce95)
- 语料是项目历史缓存的 [chinese-poetry 《全唐诗》电子整理数据](https://github.com/chinese-poetry/chinese-poetry/tree/master/%E5%85%A8%E5%94%90%E8%AF%97)。58 个 JSON 保持字节不变，合计 57,607 条数据记录。它是本项目清洗前的原始输入，不是清代刻本影像或权威校勘版。上游仓库的 [MIT 许可](https://github.com/chinese-poetry/chinese-poetry/blob/master/LICENSE) 随数据保留在 [data/LICENSE.chinese-poetry](../data/LICENSE.chinese-poetry)。逐文件哈希见 [raw_manifest.json](../data/raw_manifest.json)。
- 封面为明代钟礼《观瀑图》，大都会艺术博物馆藏，编号 1991.438.4。图像由馆方标记为公有领域。[馆藏出处](https://www.metmuseum.org/art/collection/search/44703)
- 课件末页为南宋佚名《观瀑人物图》，同为大都会艺术博物馆公有领域图像。[馆藏出处](https://www.metmuseum.org/art/collection/search/40196)

## 下载与许可

GitHub 仓库提供课程、代码、语料和实验记录。[Release](https://github.com/OakcoderX/TangShiGPT-Course/releases/tag/v1.0.0) 提供两份权重及完整学习包。512 维权重约 109 MiB，作为 Release 附件单独分发。[GitHub 大文件说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)

项目自有代码、教案和权重公开供下载学习，本次发布未附额外开源许可证。上游语料的 MIT 许可随语料保留。

解压完整学习包后，用浏览器打开 `docs/index.html` 离线学习。从源码下载时，按 [权重说明](../weights/README.md) 另取权重。
