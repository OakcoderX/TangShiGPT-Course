# 训练结句回扣前两句

沿用六层、十层 720 步后训练检查点，各自分成两个分支再走 240 步。四分支共享普通语言模型批次、结束符监督、普通唐诗保留项和学习率。两条对比分支额外看到同作者类别、同句长诗歌的正反配对，交换前两句，保留第三句和第四句，对原配结句的平均逐字对数概率给相对奖励。配对双向，发现集有效池含 62 首李白和 97 首其他作者七言四句诗。另有一首六言因无同宽度配对未使用。对比组的额外前向计算和数据呈现本身也是干预的一部分。MPS 训练循环六层普通和对比分别约 9.0、11.3 秒，十层分别约 9.8、14.6 秒。原始文件与候选加载哈希均已核对。

旧留出集只有 8 首李白与 16 首其他作者七言四句诗。两次配对复用同一批诗。李白原配与替换前文的平均差值，六层普通为 0.734 / 1.048，六层对比为 0.798 / 1.199，十层普通为 0.732 / 1.046，十层对比为 0.806 / 1.205，单位为 nats/字。两条对比分支在第一批各有一首偏向拼接文本，普通分支原配均为 8/8。其他作者的差值也增大。这个指标测到模型对更早语境的敏感度变化，未显示李白独有，也不能区分意境承接、词汇线索和原诗记忆。沿用旧诗族划分，原版可能见过测试诗，短片段与异文仍无法完全隔离。

71 首李白与 69 首其他作者的正文预测，原版损失分别为 4.3473、4.4249。六层普通为 4.3098、4.4793，六层对比为 4.3177、4.4857。十层普通为 4.3133、4.4878，十层对比为 4.3230、4.4958。两对比分支相对同深度普通续训的正文预测均略退步，四个续训版本的普通唐诗正文预测均较原版退步。

8 个新写首句各用两个固定种子生成，同条件续后三句，五言、七言各半。固定形式中原版和空扩层逐字一致，合并展示。助手匿名评阅并保存评语后揭晓。原版胜 6 组，六层对比版胜 2 组，其他三个训练版本无单独胜出，8 组难分。两组六层对比相对胜出分别出现在送舟与登峰题，换种子后未重现。仗剑题最清楚的一组有入塞行动，仍少见可辨的情感或志向。整诗评阅与留出概率结果分开解释。评阅者也设计了实验，首句预填、强制格式与同题种子相关性均限制外推。对比训练信号仅来自七言，五言结果尤其不能用来判断同体迁移。

四个后训练版本自然生成均 16/16 停在句末，原版与空扩层 0/16。所有生成与清洗唐诗、36 首样诗未检出连续 8 汉字相同，短重合、改写、异文和其他来源未知。方案、完整样本、两份匿名稿、揭晓前评语、映射、日志、预测数据、检查点与哈希均保留。可用 Python 3.12、PyTorch 2.13.0、NumPy 从 run.py、sample.py 和 audit.py 重建，保留目录结构以找到前轮权重。复验可复制本目录，以保留本次同名输出。
