# 唐诗 GPT 的李白风格后训练研究

## 实验回答

原始唐诗 GPT 是 6 层、128 宽的字符模型，约 360 万参数。现有权重下，后训练能稳定改善句末停笔。在本研究测试的数据、训练预算和生成方式下，六层续训、八层续训、十层续训均没有在新题上反复写出更自然、连贯、更像李白的整首诗。没有证据据此确定模型的容量上限。保留原版作为正式模型，所有续训权重均为实验候选。

| 对照 | 观察 |
| --- | --- |
| 原始六层与空扩层 | 空加两层或四层时保持残差分支初始输出为零。十层初始在全部旧测试样本的预测分数差为 0，受控续写与自然生成逐组相同。 |
| 六层、八层和十层全量续训 | 同一数据、步数与采样条件下，使用有效结束符监督的各组学会句末停笔。扩层有时改变正文，但整诗盲评的相对优势无法在新题上重复。 |
| 只训练新增四层 | 旧参数保持逐元素相等，普通唐诗留出损失的代价缩小，冻结版仍然无法自行停笔。 |
| 冻结版另调结束符输出行 | 只改 128 个参数，自然采样 16/16 在句末停笔，15/16 满足五言或七言、四句或八句的机械条件。屏蔽结束符后 16/16 首与冻结版逐字相同。 |
| 训练结句利用前两句 | 固定第三句的换前文诊断显示六、十层均更依赖早期上下文。该变化也出现在其他作者组，且新题盲评未反复占优。 |

## 证据和边界

- 真实唐诗按已观察到的连续 12 汉字片段归并诗族并确定发现、验证和测试分组。较广语料轮额外排除与旧验证、测试诗连续 8 汉字重合的训练诗。原模型的训练曝光、短片段与异文无法充分核实。旧诗预测只衡量固定文本，主结论依据新首句的生成。
- 每轮用相同首句、固定随机种子和采样条件对比各版本。先记录匿名诗稿的语言、画面、场景、情绪推进、志向与整体诗意，再揭晓权重版本。保持逐字相同的对照合并展示。评阅者是同一助手，部分轮次也是样诗作者。首句预填、固定字数、同题种子相关和有限题量均限制外推。不同轮次候选及题目不完全一致，不合并成一个胜率。
- 在明确四臂的十层对照中，16 组里原版胜 2、六层训练版胜 1、十层无单独胜出、难分 13。冻结实验中，原版胜 3、冻结版胜 2、难分 11。两首冻结版的局部优点出现在不同的七言题，换种子没有重现，结束符修正后的新题也未重现。局部提高体现于景物与感官的承接，整首的情绪转折、人物行动和志向依然不稳定。
- 按每轮适用的数据源检查自然与固定作品的连续 8 汉字重合。核心各轮未检出，无法排除更短重合、异文、改写和其他来源。
- 训练时间、留出正文与停止损失、原始与候选权重哈希、全部生成、盲评及映射均记录在各轮目录。原始文件 SHA-256 为 `36e7ff84f196f7a485f4fd579c92d4ab06d1c71c81f77cba37e759c9c813325d`，逐轮核对，未被替换。
