2-1 酒醒憶江東
A 酒醒憶江東，朝日低綠叢。花飛初半帖，葉落旋成空。
B 酒醒憶江東，朝朝事爲同。若非一壺酒，應是五湖風。
C 酒醒憶江東，清曉人未還。老農亦不暖，病我已成閑。

2-2 夜坐送潮聲
A 夜坐送潮聲，山開半夜明。過簾開古鏡，對火下高城。
B 夜坐送潮聲，秋風動欺客。酒酣酒不醒，月明山路苦。
C 夜坐送潮聲，樓高悵望情。蕭條腸一斷，漠漠月相明。

2-3 仗劍別慈親
A 仗劍別慈親，陳戎信有期。望中歌鳳曲，望海樂天時。
B 仗劍別慈親，防胡及此身。燕山無限淚，沙樹有啼人。
C 仗劍別慈親，雞鳴出塞塵。水中無限淚，日暮有何人。

2-4 披衣出故關
A 披衣出故關，挂席候陳山。高唐到山水，獨樹落花間。
B 披衣出故關，披衣出高樹。高低入空山，獨立無有意。
C 披衣出故關，投宿出高山。高堂對白日，獨酌登高閑。

2-5 荒亭逢故友
A 荒亭逢故友，不覺柳陰青。四面春風起，千條雨露濃。
B 荒亭逢故友，一老此秋風。天子何時見，沙鷗自落空。
C 荒亭逢故友，不見此相逢。山色無人見，江聲有鳥驚。

2-6 持書叩玉門
A 持書叩玉門，訪我遠公門。折竹拂雲扃，垂楊傍水喧。
B 持書叩玉門，買酒醉中飲。日月入門樓，光輝入寥廓。
C 持書叩玉門，起跡過山陽。日落江草綠，天寒天氣涼。

2-7 我欲援弓救遠城
A 我欲援弓救遠城，我心不知天地間。昨日浮生何所與，今人不減此身閑。
B 我欲援弓救遠城，我心不死之平生。當時無事是其間，此去無心無處處。
C 我欲援弓救遠城，平江一望不能輕。當時欲去無多事，更喜歸來是近營。

2-8 長風吹客下巴江
A 長風吹客下巴江，楚水橫流碧草間。若使明朝逢上將，不知何處渡雲山。
B 長風吹客下巴江，日暮東流萬里遙。此地已經蒼嶂裏，半年還見白雲霄。
C 長風吹客下巴江，憶得春風萬里愁。正是東風誰不見，沈香開處未還頭。

2-9 不向朱門折此腰
A 不向朱門折此腰，此身相訪又逢招。新詩却似長教得，舊宅分明是妾朝。
B 不向朱門折此腰，曉鶯花落小池圓。春風一半行人問，至今今日到何年。
C 不向朱門折此腰，更須行處到青天。東風一半眠春草，西去南來幾日煙。

2-10 欲寄孤懷與遠人
A 欲寄孤懷與遠人，不知何處問春春。金陵水淺魚搖去，白帝城邊鴈落新。
B 欲寄孤懷與遠人，一杯不賜五侯貧。都緣安得非吾事，直使人間有大身。
C 欲寄孤懷與遠人，一杯一醉不勝身。長愁正是陶公事，空作前時第一人。

2-11 雪後辭君上馬行
A 雪後辭君上馬行，遠人同向在江城。路傍病師猶未得，家在寒山遠道情。
B 雪後辭君上馬行，路人初到又經聲。誰家洞裏聞聲哭，唯有孤吟話道情。
C 雪後辭君上馬行，金華冷折一枝花。行人心斷玉關路，夜夜愁人誰解語。

2-12 霜鬢還思報一恩
A 霜鬢還思報一恩，兩心終有戀旌門。我今有淚無消息，不得長生何處言。
B 霜鬢還思報一恩，兩心終有屈爲言。廬山有路無心水，一水無雲作斷魂。
C 霜鬢還思報一恩，何人終獨憶時猨。明年昨日無歸日，不向青山借問言。
