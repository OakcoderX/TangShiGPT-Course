1-1 酒醒憶江東
A 酒醒憶江東，月明秋海中。金陵舊梅雨，白日落梅風。
B 酒醒憶江東，愁聞秋興同。葉飛霜露秋，葉動雪林紅。
C 酒醒憶江東，抗手自蕭森。送君看玉筯，相伴碧芙蓉。

1-2 夜坐送潮聲
A 夜坐送潮聲，灘聲出海清。客愁從此去，何處見秋情。
B 夜坐送潮聲，月明天氣清。山光無定處，天色有空明。
C 夜坐送潮聲，秋風去復行。孤舟方不過，一宿淚還生。

1-3 仗劍別慈親
A 仗劍別慈親，當歡自相親。韶光宜是夜，芳意與先人。
B 仗劍別慈親，當軍盡道身。陰雲連海日，走馬望塞人。
C 仗劍別慈親，橫行若遠親。青雲行有路，白日見無人。

1-4 披衣出故關
A 披衣出故關，愛酒無人煙。住近白雲裏，日西青山前。
B 披衣出故關，拂雪對新山。却顧雲霞裏，從茲雨露間。
C 披衣出故關，惜此歸何處。列食空門開，新詩誰復別。

1-5 荒亭逢故友
A 荒亭逢故友，相見此中原。山色秋猶在，江聲夜更深。
B 荒亭逢故友，社稷有前程。未有東歸日，寧惟二十年。
C 荒亭逢故友，病客每相看。昨日杏園裏，今朝上苑看。

1-6 持書叩玉門
A 持書叩玉門，顧我向蓬萊。一見五湖水，無由歸去來。
B 持書叩玉門，馬跡凌雲端。一步不可見，無由從此安。
C 持書叩玉門，駐馬入金門。一笑三千里，安禪獨一言。

1-7 我欲援弓救遠城
A 我欲援弓救遠城，身將壯氣盡寒情。兩地無人傳弓箭，一身何事不知名。
B 我欲援弓救遠城，爾何爲遝爲君平。千金買得先能畫，一箇君心不死生。
C 我欲援弓救遠城，我吹怨骨盡成兵。但知我輩不知處，何必將軍入漢城。

1-8 長風吹客下巴江
A 長風吹客下巴江，不覺君王惜屈觴。巴字不知腸欲斷，異鄉虛覺轉難分。
B 長風吹客下巴江，一醉初眠萬里愁。惆悵思歸無限恨，舊山長是謝家樓。
C 長風吹客下巴江，一醉凝情對酒筵。惆悵不知歸路遠，舊山誰見隴頭蟬。

1-9 不向朱門折此腰
A 不向朱門折此腰，莫言塵土若爲饒。黃金積子無言地，華髮無成買得秋。
B 不向朱門折此腰，蓬萊只是舊宮霄。黃金寂寞無端事，白髮楊花逐客朝。
C 不向朱門折此腰，苦從人世苦相饒。黃金畏後牀頭墮，白髮常生鬢已凋。

1-10 欲寄孤懷與遠人
A 欲寄孤懷與遠人，暫聞飄落又何因。不知世上何人見，且喜爲君一笑春。
B 欲寄孤懷與遠人，東風送我向前春。今朝不向南山去，今日自從南水濱。
C 欲寄孤懷與遠人，暮蟬高樹帶寒塵。不知何日傷心地，今日臨風不見春。

1-11 雪後辭君上馬行
A 雪後辭君上馬行，錦帆金塞起重城。關山一望難留處，不得無前淚滿纓。
B 雪後辭君上馬行，雪花開盡落花明。鏡中不見青門道，一夜空聞碧海聲。
C 雪後辭君上馬行，長安歸去盡蹉跎。野人倚櫂閑看水，夜夜無雲自到時。

1-12 霜鬢還思報一恩
A 霜鬢還思報一恩，此心何事不相論。澄波圓入澄潭曙，轉覺清光照鏡昏。
B 霜鬢還思報一恩，此心何事不相門。滿杯芳桂自相失，無醆朱顏是白源。
C 霜鬢還思報一恩，眼前何事不相論。有時已作長生事，猶有狂歌又欲言。
