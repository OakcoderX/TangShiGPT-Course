# 512 维从头训练与三个宽度的留出盲评

沿用本目录 train.py 的随机初始化、六层、八头、128 字符窗口、BF16、词表、四个通用训练轮次及李白增强的 360 批。128、256 和 512 维使用同一拆分、数据次序、批次、学习率及步数。每个注意力头宽度随整体宽度从 16、32 变为 64。模型参数数与计算预算随之变化。本轮每宽度仅一个训练初始化。

固定十二个未参与选参的首句，各两个固定采样种子。五言六首为「仗劍辭鄉里」「客散秋江晚」「對酒憶平生」「山風開石門」「渡口逢知己」「孤鴻下遠沙」。七言六首为「欲將長劍向關山」「夜半潮回思故國」「把酒臨風送遠人」「高樓醉看星河落」「黃昏踏雪尋山寺」「萬里歸來見故人」。按题轮换行旅、离别、宴酒、登临、会友和志向，押韵和平仄未强制。温度 0.65，沿用五/七言四句采样，首句一致，仅评生成的续句及其与首句的关系。自然模式另测停笔、四/八句齐整和语料重合。两个基础种子为 728417 和 519023，按题号加 137。比较三宽度的李白增强检查点，均匿名按种子和题目打乱标签。

对每个匿名文本分别打三个 0–2 分。情绪 0 为难辨或中断，1 为有起点或局部承接，2 为有可辨承接与变化或收束。志向或主体态度 0 为难辨，1 为有明确的动作、选择或态度，2 为贯穿且有发展。离别、夜景等场景可凭明确主体态度得分，不强求功名抱负。李白气质 0 为缺乏可辨的诗意组织，1 为有局部想象、语势或情景互生，2 为这些特征融进连贯整首。单列哪首整体相对更好，允许难分。先写分数与理由，封存后揭晓。重点报告每个维度跨种子的重现及相对胜出，单题重复只能支持该题。新题样本和单评阅者限制外推。按连续 8 汉字检查固定与自然输出重合。
