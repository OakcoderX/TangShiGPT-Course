1-1 仗劍辭鄉里
A 仗劍辭鄉里，臣心憶故門。秋雲不可見，獨坐淚如文。
B 仗劍辭鄉里，蒼梧向日通。登樓乘朔月，燒水引山風。
C 仗劍辭鄉里，謀臣在帝都。經年三尺劒，未得五湖夫。

1-2 客散秋江晚
A 客散秋江晚，相思復誰知。愁時不在夢，正夜落青絲。
B 客散秋江晚，相思大道長。平生不可棄，留客莫隨風。
C 客散秋江晚，潺湲夜雨時。客愁千里外，山月數重期。

1-3 對酒憶平生
A 對酒憶平生，山僧對玉弦。長江隨曉月，不見望秋星。
B 對酒憶平生，春來意已盈。野花飄草色，山鳥繞籬聲。
C 對酒憶平生，攀崖尚未成。閑臨青瑣幃，坐想白雲情。

1-4 山風開石門
A 山風開石門，竹色遶寒山。客去山中客，春歸谿上村。
B 山風開石門，竹葉藏寒水。向來多少年，去已空惆悵。
C 山風開石門，簾外開新月。古家有古人，此是空山月。

1-5 渡口逢知己
A 渡口逢知己，先生苦不迷。更無心外事，猶是國中無。
B 渡口逢知己，南戎訪北還。東林方斷日，始見夜長山。
C 渡口逢知己，全家與使君。春風和草合，竹葉出花分。

1-6 孤鴻下遠沙
A 孤鴻下遠沙，千里望江村。綠水有歸路，黃雲無限魂。
B 孤鴻下遠沙，孤騎北山東。舉手不知苦，高歌何足聞。
C 孤鴻下遠沙，北渚曲江東。自古人行處，驚霜日遶空。

1-7 欲將長劍向關山
A 欲將長劍向關山，江近東流不見還。兩畔池成無定意，百花南面有黃昏。
B 欲將長劍向關山，猶說將軍不肯閑。今日有情無定日，舊書無路更飛還。
C 欲將長劍向關山，猨鳴孤檻不相關。千里煙雲無別恨，萬重城闕有黃還。

1-8 夜半潮回思故國
A 夜半潮回思故國，南遷暫到長江浦。楚客相思繞杯酒，楚雲蕭蕭思江月。
B 夜半潮回思故國，南流夜月長相憶。歸來自是長安道，同鳥銜花似花發。
C 夜半潮回思故國，又聞歌舞醉秋風。此中自是關山暮，何處關山度蜀中。

1-9 把酒臨風送遠人
A 把酒臨風送遠人，此情終不得歸身。重來不是無心客，明日終無一字春。
B 把酒臨風送遠人，楚江秋月又歸春。酒酣不見江南望，歌舞空愁爲客人。
C 把酒臨風送遠人，東風吹去到江濱。門前不見無人見，此地無心是我身。

1-10 高樓醉看星河落
A 高樓醉看星河落，碧作東風草又浮。却憶桃家猶不去，五雲千里不相留。
B 高樓醉看星河落，聚上寒山識九衢。唯有月中無一事，一聲吟斷一聲多。
C 高樓醉看星河落，萬丈宮牆萬井秋。披衣拂人眠不得，却笑仙人下萬人。

1-11 黃昏踏雪尋山寺
A 黃昏踏雪尋山寺，白鷺羣峰上出門。行盡青青無限處，風來魂信不曾言。
B 黃昏踏雪尋山寺，白髮如花似幾春。莫道風流無限恨，門人騎馬上晨軍。
C 黃昏踏雪尋山寺，白鷺摩帆傍宿鐘。路盡雲飛無限處，門中鶴上一時鐘。

1-12 萬里歸來見故人
A 萬里歸來見故人，猶將名利在林田。三春却在天台路，萬里飛來雪嶺雲。
B 萬里歸來見故人，當時來去又成身。不知命在如今日，須向黃河舊主人。
C 萬里歸來見故人，浮雲不可望深秦。不知日日東流水，難得風流與北雲。
