2-1 仗劍辭鄉里
A 仗劍辭鄉里，天河入渭濱。平生多婦女，不敢愛君身。
B 仗劍辭鄉里，功名入海西。寒雲晴日夕，寒月夜從風。
C 仗劍辭鄉里，將軍入漢營。將軍將國命，國子愛才聲。

2-2 客散秋江晚
A 客散秋江晚，孤舟去不還。數年孤客鬢，一別幾時山。
B 客散秋江晚，春愁不可歡。明朝始已霽，寂寂正蕭條。
C 客散秋江晚，懷君不可留。故人多別鴈，故事有離愁。

2-3 對酒憶平生
A 對酒憶平生，臨流意氣平。春風吹紫陌，春酒醉朱明。
B 對酒憶平生，臨流意氣同。月明山色照，雲落隴山空。
C 對酒憶平生，臨流是白經。有情心欲盡，無盡鳥中天。

2-4 山風開石門
A 山風開石門，我夜開清景。橫風起雲起，吹落城闕夕。
B 山風開石門，山月落清暉。水隔青溪處，山開白雪飛。
C 山風開石門，幾日過江村。水隔青門近，山連白雲深。

2-5 渡口逢知己
A 渡口逢知己，行人思故鄉。客容辭國道，客自望鄉風。
B 渡口逢知己，賢才早我初。寒山連夜雨，寒雨近秋魚。
C 渡口逢知己，逢家憶故山。客來逢古草，山與浴時顏。

2-6 孤鴻下遠沙
A 孤鴻下遠沙，白馬去悠悠。此去不歸去，明朝空逝流。
B 孤鴻下遠沙，片月在江城。昔日一盈尊，今朝還送行。
C 孤鴻下遠沙，異渚望南國。朝夕動清光，歸時見高樹。

2-7 欲將長劍向關山
A 欲將長劍向關山，一別千年不可論。一種影中魚欲去，百花飛去月中還。
B 欲將長劍向關山，一半千峰到寺間。一萬年來雲脚出，萬重重到月中還。
C 欲將長劍向關山，一半分明一夜間。一片星星飛不出，萬重臺上不堪還。

2-8 夜半潮回思故國
A 夜半潮回思故國，楚雲多在暮山川。獨深寒月月明月，獨宿遠山秋色天。
B 夜半潮回思故國，東風入夢思前悲。玉關別後無人問，白雪西來在海心。
C 夜半潮回思故國，東風吹沙夜不歸。百花折得愁中月，明月銷牆淚滿衣。

2-9 把酒臨風送遠人
A 把酒臨風送遠人，花時已老過江津。前生不得閑心事，却是年來又不親。
B 把酒臨風送遠人，西樓應有錦江春。別時不敢過江北，應是思人向北津。
C 把酒臨風送遠人，萬家明月護秋塵。不知今日重相憶，却愛明年別別人。

2-10 高樓醉看星河落
A 高樓醉看星河落，萬里南行雲漢斷。一夜相思五陵上，三秋風起三更重。
B 高樓醉看星河落，遠望南行路漸賒。一別離心向西北，三湘風月一千家。
C 高樓醉看星河落，遙指吳門醉玉壺。一半花開新火合，一行鶯語一枝繁。

2-11 黃昏踏雪尋山寺
A 黃昏踏雪尋山寺，白雲始出松下人。石光不上長如此，便是沈源萬劫身。
B 黃昏踏雪尋山寺，石徑向南春更多。秋來一一重城市，夜聞涼風留不見。
C 黃昏踏雪尋山寺，白雲寒洞如流水。石上人不見天天，不見猨鳥還北飛。

2-12 萬里歸來見故人
A 萬里歸來見故人，白楊三月送春春。却憐不得君王事，更憶東園伴我身。
B 萬里歸來見故人，燕仙三百辟疆春。今朝一夜南方去，却向東園人不親。
C 萬里歸來見故人，百川三月過江春。停橈一去不歸去，只恐春來似故人。
