1-1 揮劍出柴門
A 揮劍出柴門，登高出浦原。中有一朝事，不得千里言。
B 揮劍出柴門，相逢事路人。一生俱是夢，一事不能親。
C 揮劍出柴門，登臨五老儒。一生任所得，一事可能無。

1-2 暮雨別知音
A 暮雨別知音，蕭條江樹深。秋風生遠道，天色共窮陰。
B 暮雨別知音，行人已幾春。自憐芳草色，不見故人人。
C 暮雨別知音，西風吹曉陰。空山無限月，寂寞坐思心。

1-3 醉後憶長安
A 醉後憶長安，春深謝客灘。千門如倚杖，萬里似長安。
B 醉後憶長安，春深道未安。因風吹不盡，莫遣玉顏寒。
C 醉後憶長安，春深過日歡。城高寒不絕，門靜日長寒。

1-4 欲渡大江去
A 欲渡大江去，不見遠行人。山行無遠相，却倚望長塵。
B 欲渡大江去，分行西北來。山行經雨後，楚客向秋來。
C 欲渡大江去，何曾見此山。山花若見月，天月似聞宿。

1-5 夜聞歸雁鳴
A 夜聞歸雁鳴，寂寞似江城。一身不得醉，弦聲哀苦聲。
B 夜聞歸雁鳴，寒露下江清。一雨欺秋鬢，三湘怨苦情。
C 夜聞歸雁鳴，度洞入煙城。一聲悲遠雨，滿眼愁長生。

1-6 持書入帝京
A 持書入帝京，別國望京城。千里指吳越，一朝香省榮。
B 持書入帝京，四座望光宮。使我如何處，仙人豈易空。
C 持書入帝京，大業指南征。五馬嘶春草，三花逐暮風。

1-7 平生仗劍報知己
A 平生仗劍報知己，才子分明歌聖人。一德光輝歸去國，兩成光景是天津。
B 平生仗劍報知己，將問功夫未晚歸。一半只應爲北斗，不知何處有南飛。
C 平生仗劍報知己，明主分毫是漢家。一夜巴江春水綠，兩行同賞翠華花。

1-8 我欲辭官歸故山
A 我欲辭官歸故山，今來相見淚成斑。江村日夕天山外，行盡長波不更閑。
B 我欲辭官歸故山，偶來移得暫時還。當時有事堪相問，莫爲無言也是閑。
C 我欲辭官歸故山，今來此地盡春還。無心更向巖前去，花花紅豔不相關。

1-9 江上逢君鬢已霜
A 江上逢君鬢已霜，青春未有一花芳。詩家不是移家子，疑有春風到酒郎。
B 江上逢君鬢已霜，雲泉擬愛月華光。誰家一笑還家女，流落東流入閩鄉。
C 江上逢君鬢已霜，金陵樓上手相忘。醉來不肯辭明月，腸斷東風夢裏長。

1-10 明朝策馬赴邊城
A 明朝策馬赴邊城，白鷺還從水國情。樓上秋風愁獨起，舟中春草望無行。
B 明朝策馬赴邊城，白鷺銜旗如玉京。朝下轅門猶自罷，朝爲戰士又何輕。
C 明朝策馬赴邊城，白鷺行時各自平。日出關河皆遇氣，風吹玉樹已成聲。

1-11 與君別後月空明
A 與君別後月空明，後夜無人不相見。我今日暮故鄉時，依舊須知故人意。
B 與君別後月空明，天上清秋共此情。昨夜月明愁見盡，不堪風雨夢歸聲。
C 與君別後月空明，半夜燈前一度聲。明日東風吹落盡，一年開淚滿行生。

1-12 欲問青雲何處去
A 欲問青雲何處去，始知何處是春風。空留石壁人間草，月落天涯是後宮。
B 欲問青雲何處去，可憐孤鶴夢中流。紅樓月下人間有，白髮何年有幾秋。
C 欲問青雲何處去，夢中多苦又經過。秋來未必同行路，更被君心棄却多。
