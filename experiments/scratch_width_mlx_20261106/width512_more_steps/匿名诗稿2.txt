2-1 揮劍出柴門
A 揮劍出柴門，臨軒出竹門。開緘開未盡，得意別相存。
B 揮劍出柴門，見君旋未還。遙思長安道，日日復空山。
C 揮劍出柴門，臨荒昔日恩。誰將部曲者，先入楚王孫。

2-2 暮雨別知音
A 暮雨別知音，深閨罷客吟。愁多愁白髮，不爲老青心。
B 暮雨別知音，春風聚散心。我行忘物外，不與此情深。
C 暮雨別知音，清風知幾春。情人不肯問，一爲相思人。

2-3 醉後憶長安
A 醉後憶長安，開門倚晚蘭。初開天竺寺，半出海雲竿。
B 醉後憶長安，開門在故門。地隨春草合，山向暮雲翻。
C 醉後憶長安，開門向故關。半臨春草白，一夜物華顏。

2-4 欲渡大江去
A 欲渡大江去，他年不可還。心中有離別，時復有離顏。
B 欲渡大江去，依然事去還。山光無限日，水色有行山。
C 欲渡大江去，不見吳江道。我來正載人，君去何時見。

2-5 夜聞歸雁鳴
A 夜聞歸雁鳴，秋月思無聲。幽木生曉寒，清泉上秋清。
B 夜聞歸雁鳴，玉樹度雲生。忽見霜門夢，猶悲不可行。
C 夜聞歸雁鳴，月出樹闌生。寂寞無人意，空山一夜行。

2-6 持書入帝京
A 持書入帝京，上馬下鳴雞。漢主從戎幕，胡兵入漢溪。
B 持書入帝京，佐職何高情。玉冕何時盡，金門去日生。
C 持書入帝京，乘興下黃龍。白日分明月，青山入武宮。

2-7 平生仗劍報知己
A 平生仗劍報知己，昏火無人掌上頭。可惜暫辭星漢下，何曾不許向東樓。
B 平生仗劍報知己，延壽常回在上皇。天子始聞天子寵，天恩不進御衣裳。
C 平生仗劍報知己，未得君王作報恩。却憶洛陽歸未得，九重千里望長門。

2-8 我欲辭官歸故山
A 我欲辭官歸故山，東山更欲出人間。前溪綠水分天外，北澗清江入楚關。
B 我欲辭官歸故山，東南未盡五峰間。借問謫仙何所得，何時到我在南山。
C 我欲辭官歸故山，我來無興不同攀。今朝花落傷心地，今日春來作別顏。

2-9 江上逢君鬢已霜
A 江上逢君鬢已霜，惜君同醉對江霜。故園不是無情者，惟有金陵能幾年。
B 江上逢君鬢已霜，故人何處憶江鄉。春風一片相逢日，却憶王陵有一行。
C 江上逢君鬢已霜，折腰似雪不成霜。春風一夜無由見，從此秋風是幾年。

2-10 明朝策馬赴邊城
A 明朝策馬赴邊城，此去無過此地生。陰雪雪中行此地，月樓雲外少風城。
B 明朝策馬赴邊城，此去無邊未息兵。雷鼓遠圍雲外水，雪樓寒向日邊聲。
C 明朝策馬赴邊城，漢主當軍未得名。馬足驅車逐日別，相逢何以入麻姑。

2-11 與君別後月空明
A 與君別後月空明，不見銀鉤取次行。只恐李人言已醉，何妨天子是風生。
B 與君別後月空明，不見金陵十萬重。十五六侯辭老騎，三千六節問高蹤。
C 與君別後月空明，不見離魂兩鬢生。別後幾人腸斷見，可堪情緒在青榮。

2-12 欲問青雲何處去
A 欲問青雲何處去，玉臺金鎖碧雲空。愁人不惜登樓月，惆悵仍聞更一聲。
B 欲問青雲何處去，滄波無路有波心。巴人不是無心地，却去今朝是別心。
C 欲問青雲何處去，滄波倒影無塵土。如今且向江南春，何必人間是何人。
