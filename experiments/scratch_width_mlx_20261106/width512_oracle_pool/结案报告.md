# 512 维六选一上限实验

**结论：按预定门槛，本轮没有进入自动选诗试验。** 每题两批、每批六首，两批都能各挑出一首的题为 0/6，预定门槛为 3/6。12 批中 2 批能挑出，72 首里 3 首达到三项标准。用每批第一首作为单抽对照，0/12 通过。

「攜酒謝故人，山花落秋草。客來不相逢，往事如流水。」续写交代来访未遇，并以流水收住失落。另一批没有同时过三项的诗。「聞警夜登城」有一些城头声音或天光，人物听到告警后如何应对经常没有续出。「此身願爲故人行」少数续句写出了带剑或登程，后半常离开为友而行的动机，情绪或结尾未过线。

固定 512 维基线，三道五言和三道七言，全部给定首句，固定四句，温度 0.65，72 个不同的预定种子。评阅时同题两批混排，隐藏批次、种子及采样顺序。逐首判断续写中的人物行动、情绪、收束，三项都成立才算通过。评语在揭晓前保存，SHA-256 为 `debdddcb95d8b7bfd5b7b913ed5abd73fed56b5931e90f07f02a5c7736b05628`。与清洗唐诗未检出连续 8 汉字匹配，较短重合、异文与改写无法排除。

这是单评阅者对本批候选的事后择优，验证范围为六道题、每批六首及本次生成条件。结论是本轮优质候选供应不足，未训练或试用自动选择器。原始权重与 512 维基线均逐文件哈希核对，无权重改动。按用户要求单轮结案。匿名稿、逐首评分、揭晓映射、种子、权重哈希与汇总均保留。
